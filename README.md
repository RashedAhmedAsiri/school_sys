# ثانوية الموهوبين التقنية · المنصة الذكية للمعلم

منصة عربية لمعلمي ثانوية الموهوبين التقنية: لكل معلم نظامه الخاص لتسعة فصول، مع مساعد ذكاء اصطناعي (Claude) يعرف كتابه وطلابه وخطته.

## الميزات

| القسم | ما فيه |
| --- | --- |
| الدخول | كلمة hello تُرسم لمدة ثانيتين، ثم إنشاء حساب (الاسم + كلمة مرور الموقع 123323 + كلمة مرور شخصية) أو الدخول بالاسم وكلمة المرور الشخصية |
| بعد التسجيل | صفحة لرفع ملف الكتاب (PDF / Word / PowerPoint / TXT) أو التخطي |
| الرئيسية | ترحيب hello، درس اليوم، إحصاءات الفصل، ومستطيل محادثة المساعد في الأسفل |
| تغيير الفصل | الفصول التسعة 1/1 … 3/3 في شبكة 3×3 (الصف × الشعبة)؛ كل معلم يغيّر اسم وشكل أو صورة ولون كل فصل لنفسه |
| الخطة | ملاحظات المعلم للمساعد (تُرسل مع كل طلب) + تقويم شهري لأسماء الدروس، وتخطيط ذكي يوزع الدروس تلقائياً |
| التحضير | حاضر / غائب / متأخر / بعذر حسب تاريخ اليوم، وسجل غياب كامل منذ أول يوم مع تنبيه للغياب المتكرر |
| المنهج | رفع مصادر متعددة مع Chunk RAG، عرض PowerPoint لدرس اليوم، اختبارات بنموذج إجابة، وتصحيح بالذكاء الاصطناعي يرصد الدرجات في العمود الذي تختاره |
| الطلاب | جدول مثل Excel: إضافة وحذف الطلاب (يُطبق على كل المعلمين للفصل)، أعمدة درجات خاصة بالمعلم مع مجموع ونسبة تلقائية، أوامر ذكية، تصدير وطباعة |
| المساعد الذكي | محادثة تعرف الكتاب والطلاب والخطة، وتنفذ أوامر (إضافة عمود، رصد درجات، تسجيل حضور، تعديل الخطة)، مع نطق Edge TTS وإدخال بالصوت |
| وضع الحصة | شاشة كاملة للسبورة: المساعد يشرح الدرس بصوت Edge TTS ويجيب أسئلة الطلاب بالميكروفون أو الكتابة |

**التصميم:** أخضر وأبيض مع لون حبري داكن، بلا بنفسجي ولا تدرجات ولا رموز تعبيرية، وكل الزوايا مربعة. العناوين بخط Changa والنص بخط Readex Pro. خلفيات مرسومة للمدرسة (مسارات تقنية، زخرفة كوفية، ورق رسم بياني، رموز علمية) يختار منها كل معلم أو يرفع صورته الخاصة. أيقونات ورسومات مرسومة خصيصاً للموقع، ويعمل على الجوال.

**Chunk RAG:** عند الرفع يُستخرج نص الكتاب في المتصفح ويُقسم في الخادم إلى مقاطع (~900 حرف مع تداخل). مع كل سؤال يُختار أفضل 6 مقاطع ببحث BM25 مع تطبيع الحروف العربية، فيُرسل جزء صغير بدل الكتاب كاملاً.

## التشغيل محلياً

```bash
cp .env.example .env        # ثم ضع DATABASE_URL و ANTHROPIC_API_KEY
npm install
npx prisma db push          # ينشئ الجداول
npm run dev                 # http://localhost:3000
```

أو بخادم واحد عبر Docker (يشمل قاعدة البيانات):

```bash
ANTHROPIC_API_KEY=sk-ant-... docker compose up -d
```

## الاستضافة

**الخيار المقترح: Vercel + Neon (مجاني للبداية)**

1. افتح [رابط الاستيراد](https://vercel.com/new/import?s=https%3A%2F%2Fgithub.com%2FRashedAhmedAsiri%2Fschool_sys) وسجّل الدخول بحساب GitHub، وأضف متغير البيئة `ANTHROPIC_API_KEY` ثم اضغط Deploy.
2. من تبويب Storage في المشروع أنشئ قاعدة Neon Postgres واربطها بالمشروع، فيُضاف `DATABASE_URL` تلقائياً.
3. من تبويب Deployments اضغط Redeploy، فتُنشأ الجداول تلقائياً.

كلمة مرور الموقع 123323 افتراضياً (غيّرها بالمتغير `SITE_PASSWORD`)، ومفتاح توقيع الدخول يُنشأ تلقائياً ويُحفظ في قاعدة البيانات إن لم تضع `SESSION_SECRET`.

**بدائل:** `render.yaml` لـ Render (خادم + قاعدة بيانات بضغطة واحدة)، أو `docker-compose.yml` لأي خادم VPS.

## التقنية

Next.js 15 (App Router) · PostgreSQL + Prisma · Claude API (`claude-opus-5-5` مع تفكير تكيفي وأدوات) · pptxgenjs · msedge-tts · unpdf / mammoth لاستخراج النص.

| المسار | المحتوى |
| --- | --- |
| `prisma/schema.prisma` | جداول البيانات |
| `lib/rag.ts` | تقسيم الكتب والبحث BM25 |
| `lib/ai.ts` | إعداد Claude، تعليمات النظام، أدوات المساعد |
| `lib/pptx.ts` | تصميم ملف العرض |
| `app/api/*` | واجهات البيانات والذكاء الاصطناعي |
| `app/c/[cls]/*` | صفحات الأقسام لكل فصل |
